DESCRIPTION:
This is an ant auto-chess rogue-like made for the jame gam game jam. It contains many different ant types you can use and have to fight against while buying upgrades to become even more powerful.

Feautures:
1-Fully automated battle system
2-Complex stat system
3-Fun and replay able gameplay loop

Built with:
Godot 4.7
GDScript

Installation:
Download or clone repository
Open Godot
Import project.godot file
Run project
